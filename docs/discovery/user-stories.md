# User Stories
## 1: Browse Property Listings
As a prospective buyer or renter, I want to browse property listings in one place, so that I can discover properties that may meet my needs.

## 2: View Essential Property Details
As a prospective buyer or renter, I want each property card to display essential information such as price, location, bedrooms, bathrooms, and square footage, so that I can compare properties.

## 3: Search and Filter Properties
As a prospective buyer or renter, I want to use the available search and filter controls, so that I can narrow the listings to properties relevant to my preferences.

## 4: Validate Property Data
As a person maintaining property data, I want property records to be checked against the property schema, so that invalid or incomplete records can be identified before use.

## 5: Open Property Details
As a prospective buyer or renter, I want to follow a property's details link, so that I can obtain more information about the property.

## 6: View Sponsor Information
As a local sponsor or community member, I want sponsor information to be displayed clearly, so that community members can discover participating local businesses.

## 7: Navigate Listings Accessibly
As a person using a keyboard or assistive technology, I want property listings and interactive controls to be understandable and navigable, so that I can use the listing interface independently.

## 8: Handle Invalid Property Records Safely
As a person browsing property listings, I want invalid property records to be identified and excluded from valid listing data, so that information that fails validation rules is not treated as valid.
